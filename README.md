C++ Piscine (Modules 00 → 09)
A deep dive into modern programming concepts using C++98, designed to introduce Object-Oriented Programming (OOP), memory management, and the Standard Template Library (STL).

What You’ll Learn :

🔹 Basics of C++ syntax and structure

🔹 Object-Oriented Programming: classes, inheritance, polymorphism

🔹 Canonical form (Coplien) & memory management

🔹 Templates and operator overloading

🔹 Exception handling

🔹 STL containers & algorithms (Modules 08 & 09)

Project Highlights :

🔹 Each module includes hands-on exercises that build practical understanding:

🔹 Designing robust C++ classes

🔹 Re-implementing standard behaviors

🔹 Using STL containers efficiently

🔹 Parsing and handling real-world input formats

Tech Specs :

🔹 Language: C++98

🔹 Clean code, no memory leaks

🔹 Forbidden: external libs, C functions like printf, malloc, free

🔹 Each exercise includes a Makefile
